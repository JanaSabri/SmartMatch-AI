# SmartMatch AI

SmartMatch AI is an HR recruitment dashboard designed to help teams organize applications, manage job postings, review recruitment insights, and use AI-assisted candidate matching in one structured workflow.

## Project context

- **Timeline:** 2026
- **Project type:** Software development internship project
- **Organization:** Integrated Technology Group (ITG)

## My role

During my internship at ITG, I worked across UI/UX design and frontend implementation for the HR and system administration experiences.

I designed key dashboard workflows in Figma and translated the approved designs into responsive frontend interfaces. My work focused on turning dense recruitment information into clear, consistent screens that HR users could navigate confidently.

## What I worked on

- Main HR dashboard
- Application management interfaces
- Candidate information and matching views
- Reports and recruitment insights
- Job postings management
- Create Job workflow
- AI Match Preferences
- Integrations
- Security and system settings
- Reusable dashboard UI components
- Consistent visual patterns across the platform

## Process

I first mapped the recruitment workflows and identified the information HR users needed to access quickly. I then established reusable patterns for navigation, cards, forms, tables, and dashboard components in Figma.

The designs were refined as requirements and screens evolved. After the design stage, I implemented the frontend interfaces, checked responsiveness and usability, and refined the layouts against project feedback and the approved design direction.

## Outcome

The result was a structured HR interface for managing recruitment activities, applications, job postings, reports, insights, and AI-assisted candidate matching.

This project gave me practical experience carrying work from interface design through frontend implementation while collaborating with a development team and preparing the experience for backend integration.
